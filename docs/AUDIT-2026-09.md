# PrivateType audit — September 2026

Audit of v1.0.7 (`f8c746a`), followed by the v1.0.8 hardening work. It covers what has shipped, what needed fixing, and candidate features for later versions.

## Shipped through v1.0.7

| Area | State |
|---|---|
| Dictation | Hold-to-dictate Polish and English shortcuts, live transcript preview, target-window guard before insertion |
| Model | Loaded on demand, unloaded after 5–30 idle minutes; one verified copy per Windows user shared across versions, with coordinated concurrent downloads |
| Bubble | Follows the pointer's monitor; click-through and semi-transparent; 44-band voice spectrum |
| Ready sound | Ping, Chime, Bell, or a custom WAV/MP3, with volume and preview |
| Windows integration | Version-aware Start with Windows, stable taskbar identity, tray menu with version |
| Tests | Core 64, App 91, plus the rendered LayoutProbe; all passing at audit time |

## Findings and v1.0.8 outcome

| # | Finding | Outcome |
|---|---|---|
| 1 | .NET 8 support ends on 10 Nov 2026 and every project targeted `net8.0`. | **Fixed.** All projects now target .NET 10; both workflows install the .NET 10 SDK. |
| 2 | `--threads 1` looked like it limited recognition to one CPU thread. | **Not a problem.** `--threads` is the engine's HTTP worker count, and one worker is right for a single realtime connection. ASR compute threads are hard-coded to 4 inside the pinned engine (`src/runtime/ggml/session.cpp`), so changing them needs an engine patch. Recorded in [TODO.md](../TODO.md). |
| 3 | The engine used fixed port 8098, so another program on that port blocked model loading. | **Fixed.** A free loopback port is reserved for each engine start. The engine's browser playground is also disabled with `--no-ui`. |
| 4 | Two user-facing errors were Polish in an English UI. | **Fixed.** "Text not inserted" now also explains the reason. The Polish `● Słucham` recording label is a deliberate per-language cue and stays. |
| 5 | Microphones were saved as MME positions (`wavein:N`), which shift when devices change, and names were cut off at 31 characters. | **Fixed.** WASAPI endpoint IDs are used, with Windows converting audio to 16 kHz mono. Legacy IDs migrate by unique name match; otherwise the system default is used with a warning. |
| 6 | A missed key-up (for example under an elevated foreground window) could leave recording running indefinitely. | **Fixed.** While a shortcut is held, a 250 ms watchdog checks the physical key and releases it if it is up. The late key-up is swallowed. |
| 7 | One invalid settings field reset every setting, and a missing `Shortcuts` list crashed validation. | **Fixed.** Validation is now per field group. Only invalid groups reset, and the warning names them. Schema versioning is left to Stage 2 of the vocabulary plan, which already specifies it. |
| 8 | CI ran only on release tags, and the release workflow ignored failures from all but its last test command. | **Fixed.** Added `tests.yml` for pushes to `master` and for pull requests; both workflows stop on any failing native command. |
| 9 | `TODO.md` listed shipped items, and developer and diagnostics names still said LiveDictation. | **Fixed.** `PRIVATETYPE_ENGINE_ROOT` is preferred (the old variable still works) and diagnostics exports are named `privatetype-diagnostics-*.json`. |

### Found during the work

- **The model never unloaded after startup.** Startup preloads the model but did not schedule the idle unload, so it stayed in memory until the first dictation. **Fixed.**
- **LayoutProbe started a real PrivateType.** Instantiating `App` ran `OnStartup`, which registered hotkeys, created a tray icon, and loaded the model. With another PrivateType running, it blocked on a hidden error dialog. **Fixed.** Theme resources moved to `Theme.xaml`, and the probe loads only that.
- **Decided: preload.** The model keeps loading at app start so the first dictation is fast. The tray text said "model loads on first use"; it and the README now describe the preload.

## Candidate features

| Feature | Size | Notes |
|---|---|---|
| Vocabulary and 32 locales | Large | Fully planned in [VOCABULARY_AND_LANGUAGE_IMPLEMENTATION_PLAN.md](../VOCABULARY_AND_LANGUAGE_IMPLEMENTATION_PLAN.md). Stage 1 calibration gates everything; Stage 2 (locales plus settings schema v2) can ship independently. |
| Clipboard-paste insertion | Small | Opt-in; faster for long text and works in apps that reject synthetic typing. Restores the previous clipboard contents. |
| Toggle mode | Small | Tap to start and tap to stop, for long dictations. |
| Custom modifiers | Small | Shortcuts are currently fixed to Ctrl+Shift+key. |
| Private note-taker | Medium | Save a dictation locally when no eligible target window exists. |
| Manual update check | Small–Medium | Only on user action; no background network access. |
| Code signing | Process | Avoids SmartScreen warnings on the unsigned ZIP. |

## Suggested release path

- **v1.0.8:** the hardening in this document.
- **v1.1.0:** vocabulary Stage 1 and Stage 2, clipboard-paste insertion, toggle mode.
- **v1.2.0:** vocabulary editor and packs (Stages 3–4), note-taker.
